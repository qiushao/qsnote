# qsnote

一款本地优先的 Markdown 笔记应用。写作、阅读、整理与发布，都在同一个窗口里完成。
所有数据保存在本地目录，随时可以备份和迁移。

支持 Linux、macOS 与 Windows。

![编辑与预览分屏](docs/images/split-editor.png)

## 特色功能

### 写作，专注而顺手
- 界面简单大方，没有花里胡哨的干扰。
- 编辑、阅读、分屏三种模式随时切换。
- 多标签页、自动大纲、整本笔记本搜索。
- Vim 与 VS Code 两种输入模式，
- 支持语法高亮、代码折叠、列表与表格编辑。
- 阅读区可调整主题、字体、字号、行距与正文宽度，长文阅读更自在。

### 公式与图表，离线也能看

- 支持 KaTeX 行内与块级公式。
- 支持 Mermaid、Flowchart、Graphviz、WaveDrom 与 PlantUML 图表。
- 编辑时就地预览，阅读与导出时无需联网。
- 脚注、代码高亮、提示块等 Markdown 扩展一应俱全。

![公式与图表](docs/images/diagrams.png)

### 图片，粘贴即存

- 工具栏插入、剪贴板粘贴，或直接从文件管理器拖入。
- 图片以 PNG 内嵌保存，笔记移动、备份都不会丢图。
- 已有笔记中的本地图片照常显示，支持多图插入与撤销重做。

### 四种笔记本，各司其职

- **普通笔记**：目录、多标签与拖拽整理。
- **待办清单**：分类、进行中 / 已完成、截止日期与详情。
- **电子书**：章节树、层级调整与自动编号。
- **静态站点**：不用敲命令，写作，预览，发布一条龙服务。

### 从笔记到网站

- 内置 Pure、NexT、Yilia 与 3-Jekyll 风格主题，支持采用 Hexo 目录结构的自定义适配主题，离线生成完整静态站点（无需 Node.js；Hexo 模板需转换为 QSNote 格式）。
- 分类、标签、归档、搜索与评论一应俱全。
- 一键发布到 GitHub Pages，或通过 SSH 上传到自己的服务器。

![站点预览](docs/images/site.png)

### 从笔记到电子书

- 整本或单篇导出 EPUB、PDF、CHM 与 HTML。
- 保留章节层级、图片、公式与图表，离线阅读同样完整。
- 章节自动编号会同步到导出目录与阅读器导航。

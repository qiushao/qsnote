# QSNote 使用教程

本教程面向当前仓库版本，使用中文界面名称。先完成第一篇笔记，再按需要学习待办、电子书和站点。安装及源码构建见 [BUILD.md](../BUILD.md)。

## 学习顺序

| 阶段 | 教程 | 完成后的成果 |
| --- | --- | --- |
| 入门 | [首次使用与笔记管理](getting-started.md) | 创建学习笔记本，整理目录并备份 |
| 基础 | [Markdown 写作、阅读与设置](editing.md) | 写一篇有图片、表格、链接的会议记录 |
| 进阶 | [公式与图表](diagrams.md) | 在笔记中加入公式和五类图表引擎的示例 |
| 应用 | [待办清单](todo.md) | 管理一个有分类、优先级和截止日期的计划 |
| 应用 | [电子书与导出](ebook-export.md) | 组织章节，导出 EPUB、PDF、CHM 或 HTML |
| 高级 | [静态站点与发布](static-sites.md) | 写文章、预览网站、发布到 GitHub Pages 或 SSH 服务器 |
| 扩展 | [自定义站点主题](site-themes.md) | 从示例主题开始调整模板和样式 |

## 按功能查找

- 创建、打开、关闭笔记本，目录拖拽、多标签、外部文件、搜索、保存、备份： [首次使用与笔记管理](getting-started.md)。
- 标题、格式、列表、任务框、代码、图片、表格、脚注、提示块、查找替换、阅读折叠、大纲、输入模式、拼写、快捷键、语言、托盘和更新： [Markdown 写作、阅读与设置](editing.md)。
- KaTeX、Mermaid、Flowchart、Graphviz、WaveDrom、PlantUML： [公式与图表](diagrams.md)。
- 待办分类、状态、排序、搜索、分页、删除： [待办清单](todo.md)。
- 章节排序与层级、自动编号、整本与单篇导出： [电子书与导出](ebook-export.md)。
- 文章属性、草稿、分类标签、SEO、内置主题、头像、友链、评论、独立页面、统计、自定义代码、部署： [静态站点与发布](static-sites.md)。
- 主题目录、模板占位符、条件块和子路径： [自定义站点主题](site-themes.md)。

## 示例约定

文中的名称和日期是练习数据，可自行替换。代码框展示的是要输入的内容；复制 Markdown 示例时，保留框内的反引号、空行和缩进。标为“预期结果”的段落可用来检查自己是否完成操作。

笔记本保存在本地；联网发布、远程图片、评论和统计服务另有网络需求。各教程会在相关操作旁说明条件。

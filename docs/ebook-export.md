# 电子书与导出

[教程目录](README.md) · 上一篇：[待办清单](todo.md) · 下一篇：[静态站点与发布](static-sites.md)

普通笔记本和电子书笔记本都可以导出；普通笔记本沿用目录层级，电子书额外提供章节层级调整和自动编号。静态站点顶部是“发布站点”，Todo List 没有此导出入口。

## 1. 先导出一篇笔记

1. 在普通笔记本中打开一篇笔记，例如 `项目会议.md`。
2. 点击顶部“导出电子书”。
3. “导出范围”选择“当前文档 · 项目会议.md”。默认范围是整本，需要手动切换。
4. “导出格式”选“HTML · 网页”，保存目录选一个已有文件夹。
5. 点击“导出”，完成后查看底部“已导出至…”路径，用浏览器打开该文件。

预期结果：得到含目录和正文的 HTML 文件，显示标题、图片及已渲染的公式、图表。已有同名文件会自动添加序号，不覆盖原导出文件。

首次默认保存位置为系统“文档”目录下的 `qsnote_exports`，之后会记住选择的位置。导出使用当前编辑内容快照；仍建议先保存，便于后续备份原稿。

## 2. 创建有层级的电子书

新建“项目手册”，类型选择“电子书（章节目录 · 多格式导出）”。在左侧空白处右键“添加章节”，创建“入门”和“进阶”；在“入门”上右键“添加子章节”，创建“安装”和“第一篇笔记”。

```text
入门
├── 安装
└── 第一篇笔记
进阶
```

每个章节本身都可以有正文。“入门”可写导读，“安装”写步骤，“第一篇笔记”写操作练习。章节是文档之间的结构；文内 `#`、`##` 标题用于各文档自身的大纲。

## 3. 调整章节顺序和层级

| 右键操作 | 练习和结果 |
| --- | --- |
| 上移 / 下移 | 将“第一篇笔记”移到“安装”前，再移回；调整同级顺序 |
| 缩进为子章节 | 将“进阶”缩进到它前面的章节下；没有可作为父项的前一同级项时不可用 |
| 提升层级 | 把已缩进的“进阶”提升回顶层；顶层不能继续提升 |
| 重命名 | 把“进阶”改为“发布与导出” |
| 删除 | 删除章节及其子章节，确认后不可恢复 |

电子书的层级和顺序使用上述右键操作调整；树内拖拽整理仅用于普通笔记本。

勾选顶部“章节自动编号”，预期看到 `1 入门`、`1.1 安装`、`1.2 第一篇笔记`、`2 发布与导出`。编号按当前树生成，并同步到导出目录与阅读器导航；无需自己在章节名称前写数字。正文中的手写标题不会因此自动改写。

## 4. 选择整本或当前文档

整本导出保留章节树顺序与层级。把第一篇练习的范围改成“整本电子书 · 项目手册”，再导出即可得到完整手册。

“当前文档”只导出选中的那一个文档，**不包含它的子章节**。例如当前选中“入门”，只会导出导读正文，不包括“安装”和“第一篇笔记”。若没有打开当前笔记本中的可导出文档，范围框只提供整本。

普通笔记本的文件夹在整本导出中用于组织目录；想控制出版顺序和自动编号时，可建立电子书笔记本，再逐章复制内容和所需附件。

## 5. 四种格式分别怎么用

| 格式 | 示例用途 | 条件与结果 |
| --- | --- | --- |
| EPUB | 把项目手册放进电子书阅读器 | 输出 `.epub`，有分层导航；具体显示效果取决于阅读器 |
| PDF | 分享固定分页版本或打印 | 输出 `.pdf`，A4 纵向、15 mm 页边距，并生成章节书签 |
| CHM | 制作本地帮助文档 | 输出 `.chm`；需要外部 CHM 编译器 |
| HTML | 用浏览器查看或发送单文件 | 输出 `.html`，图片资源内嵌，适合先检查导出效果 |

依次选择不同格式导出，打开结果检查章节目录跳转。HTML、PDF 和 EPUB 不需要额外电子书转换程序；含 PlantUML 的原稿仍需其本地运行环境。

CHM 优先查找 `PATH` 中的 `chmcmd`（Free Pascal 工具，Linux 常由 `fp-utils` 提供）；Windows 也可使用 HTML Help Workshop 的 `hhc`。找不到编译器时“导出”按钮不可用，安装并让应用能找到后重试。

## 6. 图片、链接和排版

导出会处理本地图片、内嵌图片和 HTTP(S) 图片，并把资源放入导出结果。远程图片需要在导出时成功下载；离线导出前，先通过粘贴或本地文件替代远程图片。公式和图表会在导出阶段渲染，阅读导出文件时无需再运行图表引擎。

练习：在“安装”正文中插入一张本地截图、一个公式和一张流程图，再整本导出 HTML。断网后打开生成文件，确认三者仍可见。

整本中互相引用的本地章节链接会转换为书内跳转。未包含在本次导出范围内的本地目标会移除链接地址，因此只导出单篇时，跨文档链接可能变为普通文字。链接目标不会因为存在引用就自动加入。正文使用正常相对路径，并在成品中实际点击检查。

应用里的阅读主题、字体和正文宽度只影响阅读区。导出使用自己的排版；目前导出对话框只提供范围、格式和保存目录，不提供封面设计、纸张尺寸等选项。

## 7. 排错与交付检查

| 现象 | 处理 |
| --- | --- |
| 导出按钮不可用 | 检查目录已存在、笔记本有内容，CHM 编译器可用 |
| 图片读取失败 | 检查相对路径以文档目录为基准；远程图片能否下载 |
| 公式或图表报错 | 先在分屏预览修正语法，必要时检查 PlantUML 运行环境 |
| 目录层级不符合预期 | 返回左侧树调整顺序和层级，再重新导出 |
| 想只导出一章，却得到整本 | 重新打开导出窗口并明确选择“当前文档” |

交付前打开实际文件，检查目录、首尾章节、中文字符、图片和跨章链接；PDF 再检查分页、书签，EPUB 再用目标阅读器检查导航。导出成品不能替代含 `_index.json` 的笔记本备份。

# 首次使用与笔记管理

[教程目录](README.md) · 下一篇：[Markdown 写作、阅读与设置](editing.md)

## 1. 选择笔记本类型

| 类型 | 组织方式 | 练习用途 |
| --- | --- | --- |
| 普通笔记本 | 文件夹和 Markdown 笔记 | 学习笔记、会议记录 |
| Todo List | 分类和事项 | 每周计划 |
| 电子书 | 有顺序和层级的章节 | 项目手册 |
| 静态站点 | 带分类、标签等属性的文章 | 个人博客 |

本篇先使用普通笔记本。其他类型分别有独立教程；新建时按用途选择。

## 2. 创建第一篇笔记

1. 启动 QSNote，点击顶部笔记本选择框旁的“新建笔记本”按钮。
2. 名称填“学习笔记”，类型选“普通笔记本（目录 + 元数据文件）”。
3. 查看“保存位置”，需要时点“浏览…”选择父目录。程序会在父目录内创建以笔记本命名的目录；重名时追加序号。
4. 点击“创建”。在左侧内容树空白处右键，选择“新建笔记”，输入“第一篇”。普通笔记名称会自动补上 `.md`。
5. 在编辑区输入：

```markdown
# 我的学习计划

今天开始用 QSNote 整理笔记。

## 本周目标

- 学习 Markdown
- 整理会议记录
- 导出一份阅读材料
```

6. 点击工具栏“分屏”，同时查看源码和排版。再点击“预览”阅读，点击“编辑”继续写作。
7. 停止修改约 5 秒后会自动保存，也可以使用系统保存快捷键（Linux/Windows 通常为 `Ctrl+S`，macOS 通常为 `Cmd+S`）。

预期结果：左侧有 `第一篇.md`，右侧大纲中能看到“我的学习计划”和“本周目标”；关闭并重新启动后仍能打开内容。保存失败会弹出错误，需解决提示中的路径或权限问题后再次保存。

默认保存父目录是系统“文档”目录下的 `qsnote`；没有可用文档目录时使用用户主目录下的 `qsnote`。实际位置以创建窗口显示为准。

## 3. 认识工作区

| 区域 | 用法 |
| --- | --- |
| 顶部笔记本选择框 | 切换已打开的笔记本 |
| 搜索框 | 按标题或正文搜索当前笔记本 |
| 左侧树 | 选择笔记，右键新建、重命名、删除和管理笔记本 |
| 中间标签栏 | 在多篇已打开的文档间切换 |
| 编辑工具栏 | 插入格式、图片、表格、图表，切换编辑/预览/分屏 |
| 右侧大纲 | 根据正文标题生成导航，点击跳转 |
| 底部状态 | 查看字数、行数和当前模式，或导出结果路径 |

顶部“收起/展开笔记本栏”和“收起/展开右侧栏”按钮可腾出写作空间；分屏时可以拖动分隔线调整比例。窗口较窄时，部分按钮文字会缩短，例如“导出电子书”显示为“导出”。

## 4. 用文件夹整理笔记

1. 在普通笔记本左侧空白处右键，选择“新建文件夹”，命名为“课程”。
2. 在“课程”上右键“新建笔记”，创建 `Markdown 入门.md`。
3. 再创建“会议”文件夹，将 `第一篇.md` 拖到其中。拖拽也可以调整树中顺序。
4. 在笔记或文件夹上右键“重命名”，例如改成 `第一周计划.md`。

预期结构：

```text
学习笔记/
├── 课程/
│   └── Markdown 入门.md
└── 会议/
    └── 第一周计划.md
```

创建顶层项目时在空白处右键；创建子项目时在目标文件夹上右键。重命名和移动会影响磁盘路径，已有手写相对链接应重新核对。

搜索结果视图不允许拖拽整理，先清空搜索恢复完整目录树再移动。

右键“删除”会删除所选内容及其子项，确认后不可通过编辑器撤销恢复。仅想从列表移除笔记本时使用“关闭笔记本”。

## 5. 多标签和外部文件

依次点击两篇笔记即可打开多个标签；拖动标签可调整顺序。点击标签关闭按钮只关闭页面，不删除笔记。

右键标签可以：

- “复制相对路径”或“复制绝对路径”：例如取得图片引用或链接所需的位置。
- “打开路径”：打开文件所在目录。
- “定位节点”：返回该文档所属笔记本并定位左侧节点；外部文件没有笔记本节点。
- “全部保存”：保存当前修改。
- “关闭其他标签”或“关闭所有标签”：清理工作区。

从文件管理器把一个 UTF-8 文本文件（如 `草稿.md`）拖入中间工作区，可作为外部文档打开。**修改会写回原文件，不会自动复制到当前笔记本或加入左侧树。** 要纳入笔记本，先新建笔记，再复制正文；有相对图片链接时也要安置图片。应用会拒绝无效的 UTF-8 文本。

## 6. 搜索当前笔记本

1. 在不同笔记正文写入“项目复盘”。
2. 按 `Ctrl+Shift+F` 聚焦顶部搜索框，输入“复盘”。
3. 查看筛选出的笔记及正文片段，点击打开。
4. 清空搜索框恢复完整树；焦点在搜索框内时按 `Esc` 也可清空。

搜索匹配标题或正文，不区分大小写，范围是**当前笔记本**，不是所有已打开标签或全部笔记本。单篇文档内定位和替换见[编辑教程](editing.md)。

## 7. 关闭、重新打开和迁移

在左侧右键菜单选择“关闭笔记本”，确认后该本从列表移除，磁盘内容保留。以后在左侧右键“打开笔记本…”，选择原来的笔记本根目录。

根目录必须含 `_index.json`。它记录笔记结构、顺序、属性及笔记本配置；普通 Markdown 文件夹不能直接当成 QSNote 笔记本打开，放入额外的 `.md` 文件也不会自动加入笔记树。

迁移“学习笔记”的步骤：

1. 保存全部修改，然后关闭该笔记本。
2. 复制整个“学习笔记”目录到新位置，包括 `_index.json`、所有 Markdown 文件、图片等附件。
3. 在 QSNote 中通过“打开笔记本…”选择新位置。
4. 检查目录层级、正文、图片和链接，再决定是否清理旧副本。

只移动 Markdown 会丢失笔记本结构和元数据。完整备份应复制整本目录；站点还应包含 `source/` 和自定义主题。使用绝对路径引用的外部资源需要单独迁移或改成相对路径。全局 `notebooks.json` 只是应用数据目录中的笔记本登记信息，不能替代正文备份。

外部程序修改已打开的笔记后，当前编辑器不保证自动重载。先保存并关闭笔记本，再用外部程序修改，完成后重新打开，可避免两个编辑器互相覆盖。

# 待办清单

[教程目录](README.md) · 上一篇：[公式与图表](diagrams.md) · 下一篇：[电子书与导出](ebook-export.md)

## 1. 创建每周计划

1. 新建笔记本“每周计划”，类型选“Todo List（分类 · 待办事项）”。
2. 点击“新建分类”，输入“工作”；再创建“生活”。
3. 在“进行中”状态点击“新建事项”，标题填“完成使用教程”，分类选“工作”。
4. 选中事项，在右侧“事项详情”把优先级设成“高”，勾选“截止日期”，选择计划完成日期。
5. 在正文写“先完成入门章节，再逐项核对示例”。

预期结果：工作分类下出现事项，详情显示创建时间、标题、状态、分类、优先级、日期和正文。修改会保存，无需单独给事项提交表单。右侧详情被收起时，点击顶部“收起/展开右侧栏”。

事项详情正文是文本输入区；这里不会自动具备普通笔记的 Markdown 分屏工作区。

## 2. 修改和完成事项

再创建两项：

| 标题 | 分类 | 优先级 | 截止日期 |
| --- | --- | --- | --- |
| 检查截图 | 工作 | 中 | 比教程晚一天 |
| 整理书桌 | 生活 | 低 | 不启用 |

选择事项后可直接修改标题、正文、分类和优先级。取消“截止日期”勾选即可去掉日期。日期用于记录和排序，当前没有定时通知入口。

完成“检查截图”后勾选列表复选框或详情里的“已完成”，它会从“进行中”消失。切换顶部状态为“已完成”即可找到；取消勾选会移回“进行中”。“新建事项”按钮在进行中视图显示。

## 3. 分类、搜索和排序一起用

1. 左侧选择“工作”，仅查看工作事项；选择“全部”取消分类限制。
2. 顶部搜索框输入“教程”，按标题或详情正文匹配，不区分大小写。
3. 在排序框依次选择优先级、创建日期、截止日期，观察顺序变化。

| 排序方式 | 结果 |
| --- | --- |
| 按优先级（高到低） | 高优先级事项排在前面 |
| 按创建日期（新到旧） | 新建事项在前 |
| 按截止日期（近到远） | 有日期的事项按早晚排列，没有日期的排在后面 |

状态、分类、关键词会同时限制结果。例如“工作 + 已完成 + 教程”只显示工作分类里已完成且标题或正文含“教程”的事项。找不到内容时，先切换“全部”、清空搜索，再检查状态。

每页显示 20 项，超过一页时使用“上一页/下一页”，页码旁显示筛选后的总项数。可连续添加 21 个练习事项来观察分页。

## 4. 管理分类

在左侧分类上右键：

- “新建分类”：例如创建“学习”。
- “重命名分类”：把“工作”改为“项目”，其中事项会保留在改名后的分类。
- “删除分类”：其中事项移入“默认”，不会删除事项。

“全部”是筛选入口；内置“默认”分类不能重命名或删除。也可以在事项详情中逐个调整分类。

## 5. 删除和清理

点击事项旁的删除按钮并确认，可永久删除单个事项。

切换“已完成”后，可以“清空已完成事项”。**这会删除当前笔记本所有分类、所有分页中的全部已完成事项，不受当前搜索条件限制。** 例如屏幕只筛选出“检查截图”，但别的分类还有已完成事项，清空时也会一起删除。请核对确认框中的总数。

删除无法通过正文撤销恢复；需要保留历史时，让事项留在已完成视图即可。备份方法与其他笔记本相同：复制包含 `_index.json` 的完整目录，参见[首次使用](getting-started.md)。Todo List 没有电子书导出入口。

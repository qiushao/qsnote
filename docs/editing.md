## 1. 从会议记录开始

新建 `项目会议.md`，复制下面的内容，切换“分屏”观察结果：

````markdown
# 项目会议

## 结论

本周优先完成 **文档**，*界面调整* 留到下周。
~~旧计划~~ 已取消，==周五验收==。

> 先让新同事能够独立完成第一次操作。

## 行动项

- [ ] 补齐使用教程
- [x] 确定章节结构

1. 写入门示例
2. 检查操作结果

## 资源

[本地计划](第一周计划.md)

使用 `print()` 输出检查信息：

```python
print("文档已完成")
```

---

下次会议继续检查示例。
````

预期结果：标题分级显示，文字有粗体、斜体、删除线和高亮，列表、引用与代码各有排版。“本地计划”链接需要同目录确实存在 `第一周计划.md`；可改成你自己的文件名。

工具栏可以插入标题、加粗、高亮、链接、图片、无序/有序/任务列表、引用、行内代码、代码块、公式和表格。先选择文本再点击格式按钮，可快速给已有文字加格式。斜体和删除线可直接使用 Markdown 语法或快捷键。

标题用 `#` 到 `######` 表示六个级别，井号后有空格；编辑区右键“编辑器选项 → 标题级别”也可切换为 H1～H6 或正文。下文的编辑区右键功能均在“编辑器选项”子菜单中。段落间留一个空行。

## 2. 表格、图片和链接

### 表格

点击“表格”，输入数据行数 `2`、列数 `3`，确认后填写内容：

```markdown
| 事项 | 负责人 | 状态 |
| --- | --- | --- |
| 教程 | 小林 | 进行中 |
| 检查 | 小周 | 待开始 |
```

在编辑器设置的 Markdown 页启用“可编辑表格就地预览”，可在编辑区使用表格预览编辑内容。“自动对齐表格源码”用于整理 Markdown 源码的列。预览区会显示两条数据记录。

### 三种插图方式

1. **工具栏**：点击“图片”，选择本地图片。
2. **粘贴**：复制截图或图片，在编辑区粘贴。
3. **拖入**：把一张或多张图片文件拖到编辑区。

有文档目录时，工具栏选择或拖入的图片会复制到文档旁的 `resources/images/`，保留原格式；剪贴板图像会保存为 PNG。Markdown 使用相对路径，例如 `![](resources/images/meeting.png)`。同名图片自动追加序号。插入后用撤销/重做按钮可撤销或恢复正文中的图片引用。

没有文档目录时才回退为 PNG 内嵌，形式类似 `![说明](data:image/png;base64,...)`；已有内嵌图片也能显示。备份、移动笔记时应同时保留 `resources/images/`，不要只复制 `.md` 文件。

也可以沿用本地相对路径：先在笔记旁建立 `images` 目录放入 `meeting.png`，再写：

```markdown
![会议白板](images/meeting.png)

![缩略图](images/meeting.png =320x200)
```

相对路径以当前文档所在目录为基准。迁移笔记时要保留相对目录；远程图片需要联网，离线使用时可改为粘贴或本地图片。

在预览区点击普通图片，可打开大图查看，再点击弹出的图片区域或按 `Esc` 关闭。例如点击刚插入的会议白板，查看缩略图中看不清的文字。

### 链接与锚点跳转

通用语法是 `[显示文字](目标地址)`。也可以点击工具栏“链接”，分别填写“文字”和“地址”。在**预览模式或分屏右侧**点击链接即可跳转。

#### 同一篇笔记内跳转

使用 `[显示文字](#标题锚点)`。把下面的完整示例粘贴到一篇笔记中：

```markdown
# 使用说明

[查看安装步骤](#安装步骤)
[查看英文示例](#usage-example)

## 安装步骤

这里填写安装说明。

## Usage Example

这里填写使用示例。
```

预期结果：点击“查看安装步骤”定位到中文标题；点击“查看英文示例”定位到 `Usage Example`。目标章节被折叠时，跳转会展开相关区域。

标题会自动生成锚点，不需要手动给每个标题加编号：

| 正文标题 | 链接中的锚点 | 规则 |
| --- | --- | --- |
| `## 安装步骤` | `#安装步骤` | 中文保持原文 |
| `## Usage Example` | `#usage-example` | 英文字母转小写，空白替换为短横线 |
| `### 第一步 安装` | `#第一步-安装` | 中文与英文使用相同的空白处理规则 |

标题前的 `#` 数量只表示层级，不是锚点的一部分。尽量使用不重复、少标点的标题；重名标题会生成不同锚点，难以确定时用右侧大纲定位。修改标题后，应同步修改指向它的链接。

#### 笔记之间跳转

使用 `[显示文字](相对文件路径)`；要定位到另一篇笔记中的标题，则在文件路径后加 `#标题锚点`。

假设笔记目录如下，当前正在编辑 `指南/使用说明.md`：

```text
项目笔记/
├── 项目计划.md
└── 指南/
    ├── 使用说明.md
    ├── 安装.md
    └── 示例/
        └── 快速开始.md
```

在 `使用说明.md` 中写：

```markdown
[打开同目录笔记](安装.md)
[打开子目录笔记](示例/快速开始.md)
[打开上级目录笔记](../项目计划.md)
[跳到安装笔记的指定章节](安装.md#环境准备)
```

在 `安装.md` 中添加标题 `## 环境准备` 并保存。预期结果：前三个链接分别打开对应笔记，第四个链接打开 `安装.md` 并定位到“环境准备”。

路径以**当前笔记所在目录**为基准，不是笔记本根目录；`../` 表示上一级目录。填写真实文件名和扩展名，目录分隔符统一写 `/`。文件名包含空格时，可用尖括号包住整个目标，例如 `[英文笔记](<Daily Notes.md#usage-example>)`。

目标属于 QSNote 中已打开的笔记本时，会在应用内打开并定位，包括其他已打开笔记本中的文档；其他本地文件交给系统默认程序处理。跨笔记本链接仍按磁盘相对路径填写。普通网页链接如 `[网站](https://example.com)` 会交给外部浏览器打开。

#### 跳转失败时检查

- 提示目标不存在：核对相对目录、文件名及扩展名；笔记移动或重命名后重新检查链接。
- 文档打开但没有定位：确认目标标题存在，锚点的大小写、空格转换和标点与标题一致。
- 点击后由其他程序打开：确认目标所在的 QSNote 笔记本已通过“打开笔记本…”加入应用。
- 编辑区点击没有跳转：切换到预览，或点击分屏右侧的排版链接。

## 3. 扩展 Markdown

### 脚注、上下标和表情

```markdown
这个结论有一段补充说明。[^source]

水的化学式是 H~2~O，平方写作 x^2^。:smile:

[^source]: 这里填写来源或解释。
```

预期结果：正文出现脚注跳转，底部显示说明，数字呈现上下标，表情短码转为表情。

### 提示块

```markdown
::: alert-info
先保存，再导出。
:::

::: alert-warning
导出前检查图片路径。
:::
```

预期结果：两段文字呈现为提示块。使用 `alert-...` 容器语法，不能直接套用其他平台的提示块写法。

### 文内目录

在含有多个 Markdown 标题的文档中，独立一行写 `[[toc]]`，预览会生成可点击目录。右侧大纲则无需写任何占位符即可使用。

正文支持部分 HTML，并会过滤脚本等不允许的内容。例如 `<kbd>Enter</kbd>` 可用于按键说明；不要把站点自定义脚本粘进正文期待执行，站点代码入口见[站点教程](static-sites.md)。

## 4. 编辑、预览与分屏

| 模式 | 操作示例 |
| --- | --- |
| 编辑 | 写源码；启用就地预览后可在编辑器里看到图片、表格、公式和图表 |
| 预览 | 阅读排版结果，点击链接、标题、任务框 |
| 分屏 | 左侧写作、右侧看结果，两侧滚动联动 |

点击右侧大纲的“行动项”，可跳到对应标题。在预览中点击 `- [ ]` 任务框会把源码改成 `- [x]`，再次点击恢复；这类正文任务框与独立的 Todo List 笔记本分别管理。

预览区右键有以下入口：

- **查找阅读内容…**：例如输入“教程”，使用“上一个/下一个”；可区分大小写，查找会展开折叠章节。
- **跳转到标题…**：输入“行动”，回车或双击匹配标题跳转。
- 阅读区获得焦点时，也可以按 `Ctrl+G` 打开标题跳转窗口。
- **标题折叠**：启用后使用标题处的折叠控件收起章节；也可“折叠所有章节”或“展开所有章节”。折叠只改变阅读展示。
- **阅读设置…**：设置所有笔记阅读区的配色、字体、字号、行距和正文宽度。

试把阅读配色设成“纸张”，字号设为 `18 px`、行距 `1.8`、最大正文宽度 `900 px`，确认后阅读长文。配色还有浅色、深色；宽度 `0` 表示不限。阅读设置与编辑器字体、应用 UI 字体分别控制不同区域，也不是站点主题或电子书排版设置。

## 5. 查找和替换

编辑区右键“查找和替换…”，或在编辑区使用系统查找快捷键。输入查找“下周”、替换为“下个迭代”，用“下一个”定位，再点击“替换”；“全部替换”会处理当前文档全部匹配。

可选“区分大小写”“全词”“正则表达式”。例如查找 `2026-\d{2}-\d{2}`，勾选正则表达式，可定位正文中的 `2026-10-25`。替换前先用“上一个/下一个”确认匹配范围；非法表达式会提示“正则表达式无效”。

焦点在预览区时，查找快捷键打开阅读区查找；没有打开文档时转到笔记本搜索。替换只用于编辑文本。

## 6. 调整编辑器

左上角“设置 → 编辑器设置”可以统一设置所有笔记，也可从编辑区右键“编辑器设置…”进入。保存后生效。

| 位置 | 功能与练习 |
| --- | --- |
| 文本 → 输入模式 | 普通、Vim、VS Code。先用普通模式；熟悉 Vim 的用户可切换后按 `i` 输入、`Esc` 回到普通状态 |
| 文本 → 行号 | 隐藏、绝对或相对；例如调试代码笔记时启用绝对行号 |
| 文本 → 换行 | 不换行、按单词、任意位置、优先按单词；长中文段落可使用优先按单词 |
| 文本 → 光标居中 | 不居中、始终居中、到达底部时居中；长文写作可试“始终居中” |
| 文本 → 字体、字号与缩放增量 | 例如使用等宽字体，字号 `14 pt`；缩放增量用于在基础字号上调整 |
| 文本 → Tab 宽度、展开为空格 | 例如设置宽度 `4` 并展开为空格，使代码缩进一致 |
| 文本 → 行距、正文宽度 | 例如行距 `1.5`，宽度 `1000 px`；宽度 `0` 不限 |
| 文本 → 允许文本折叠 | 启用后可用右键“折叠当前区域/展开当前区域”整理长文 |
| 文本 → 标记 Tab 和行尾空白 | 检查代码块缩进或多余空白 |
| Markdown → 就地预览 | 总开关以及图片、可编辑表格、公式、图表各自开关；例如只保留图片预览 |
| Markdown → 限制就地预览宽度 | 避免大图占据过宽空间 |
| Markdown → 自动折叠已有预览的源码 | 减少源码和渲染结果同时占用的空间；需要查看源码时展开区域或关闭此项 |
| Markdown → 缩短显示过长的链接地址 | 减少长链接对编辑视线的干扰 |
| Markdown → 自动对齐表格、自动编号有序列表 | 连续录入表格或步骤时使用 |
| 拼写 → 启用拼写检查、自动识别语言、词典 | 安装所需 Hunspell 词典后选用；没有词典时界面会提示 |

右键菜单还提供“补全”“放大”“缩小”，以及输入模式、行号、换行、就地预览、列表编号、光标居中和拼写检查的快捷开关。例如输入部分内容后右键“补全”，查看编辑器当前可提供的候选。

Vim 与 VS Code 是编辑器输入模式，不会运行 Vim 插件或 VS Code 扩展。模式内按键可能影响通用编辑操作，可通过右键菜单切回“普通”。

## 7. 应用设置

点击左上角“设置”：

- **常用设置**：语言选“跟随系统”“简体中文”或“English”；保存并重启后切换语言。UI 字体和字号影响菜单、按钮等界面文字。
- **关闭时最小化到系统托盘**：勾选并保存后，关闭窗口保留程序运行；用托盘菜单“显示主窗口”恢复，“退出”结束。系统没有可用托盘时正常退出。
- **启动时检查更新**：通过 GitHub 查询新版本。也可在“关于”点击“检查更新”，有新版本时前往下载；此功能不是自动安装更新。
- **关于**：查看版本、项目主页和版本下载入口。

## 8. 常用快捷键速查

| 操作 | 快捷键 |
| --- | --- |
| 保存、查找、加粗、斜体 | Linux/Windows 通常为 `Ctrl+S`、`Ctrl+F`、`Ctrl+B`、`Ctrl+I`；macOS 对应系统常用 `Cmd` 组合 |
| 查找替换 | 系统替换快捷键，常见为 `Ctrl+H`；各平台也可使用右键菜单 |
| 搜索当前笔记本 | `Ctrl+Shift+F` |
| 切换编辑与预览 | `Ctrl+E`；分屏使用工具栏按钮 |
| 删除线 | `Ctrl+Shift+S` |
| 插入链接 | `Ctrl+K` |
| 撤销、重做 | 系统编辑快捷键或工具栏按钮 |
| 清空笔记本搜索 | 焦点在搜索框时按 `Esc` |

表中明确写出的 `Ctrl` 组合来自应用定义；系统标准快捷键会按平台映射。键位冲突时使用工具栏或右键菜单即可完成相同操作。
